================================================================
  股指期货持仓追踪 · 安卓APP  手把手安装教程
  （面向完全不懂代码的人，按步骤做即可，全程约 40 分钟）
================================================================

你需要准备两样东西：
  1. 一个 GitHub 账号（免费，注册即可）
  2. 能打开 github.com 的网络 —— 国内一般要开梯子软件（VPN）


----------------------------------------------------------------
  特别说明：梯子只在电脑上用
----------------------------------------------------------------
  · 电脑上：要访问 github.com，所以先开梯子。
  · 编译过程：在 GitHub 的服务器上做，跟你的网络快慢无关。
  · 手机上：APP 只访问东方财富、新浪、中金所这些国内网站，
    手机永远不需要挂梯子。


================================================================
  第 1 步：注册 / 登录 GitHub（约 3 分钟）
================================================================
1. 先打开你的梯子软件，确认能正常上网。
2. 浏览器打开 https://github.com
3. 右上角点 Sign up（注册）：填邮箱 → 填密码 → 填用户名 → 完成人机验证
   → 去邮箱收验证码填上 → 注册完成。
   （如果已经有账号，直接点 Sign in 登录即可。）
4. 登录后能看到右上角有你的头像，就说明成功了。


================================================================
  第 2 步：新建一个“空”仓库（约 2 分钟）
================================================================
1. 登录后，看页面右上角，点那个 “+” 号 → 选 New repository。
   （或者直接打开 https://github.com/new ）
2. Repository name（仓库名）随便填，比如填：index-futures-app
3. 选 Public（公开）。（Private 私有也能用，但公开更省事。）
4. 下面这几个框【一个都不要勾】：
     [ ] Add a README file
     [ ] Add .gitignore
     [ ] Choose a license
   —— 一定要保持全是空的，勾了会导致后面上传失败。
5. 点绿色按钮 Create repository。
6. 建好后页面会显示一个网址，长得像这样：
     https://github.com/你的用户名/index-futures-app.git
   把它复制下来（页面上有绿色按钮 Code，点开也能复制）。
   这个网址就是“仓库地址”，第 3 步要用。


================================================================
  第 3 步：把代码传上去（约 3 分钟）
================================================================
1. 打开文件夹：
     桌面 → 股指期货持仓统计 → android_app
2. 找到【推送到GitHub.bat】，双击它。
   （如果杀毒软件报警，选“允许运行 / 更多信息 → 仍要运行”。）
3. 黑窗口里问你要仓库地址：
     把第 2 步复制的网址粘贴进去（右键粘贴，或 Ctrl+V），按回车。
4. 接着问你要不要代理端口：
     · 你开了梯子 → 填梯子软件的端口号，按回车。
       常见端口：Clash / Clash Verge 填 7890
                v2rayN 填 10809
                Shadowsocks 填 1080
       （不知道就去看梯子软件的设置页，里面写着“端口/Port”。）
     · 没开梯子、网络能直连 → 直接按回车跳过。
5. 这时会弹出 GitHub 登录窗口 → 选“用浏览器登录(Sign in with your browser)”
   → 按提示点授权 → 登录成功。
6. 看到黑窗口显示  UPLOADED OK!  就说明传上去了。
   如果显示 UPLOAD FAILED，看窗口里给的 4 个原因，改完重新双击再跑一次即可，
   不会弄坏任何东西。


================================================================
  第 4 步：等云端编译 APK（约 20～40 分钟，你在旁边等着就行）
================================================================
1. 回到 github.com，打开你刚建的仓库页面。
2. 点页面上方一排标签里的【Actions】。
3. 正常情况下，你会看到一条正在跑的任务（黄色小圆点在转），
   名字叫 “Build Android APK”。这就是在编译了，不用管它。
4. 如果 Actions 页面是空的、没有任何任务：
   左侧点 “Build Android APK” → 右边点 “Run workflow” → 再点绿色按钮。
5. 首次编译要下载约 1.5GB 的安卓开发工具，所以慢，20～40 分钟都正常。
   等小圆点变成【绿色对勾】就是成功；变成【红色叉】就是失败了。


================================================================
  第 5 步：下载 APK 文件
================================================================
1. 编译成功（绿色对勾）后，点进那一条任务。
2. 拉到页面最下面，会有一块叫【Artifacts】的地方，
   里面有一项：index-futures-tracker-apk
3. 点它下载，得到一个 .zip 压缩包。
4. 解压这个压缩包，里面就是 .apk 文件（名字类似
   indexfuturestracker-1.0-arm64-v8a-debug.apk）。
   注意：解压出来的可能是两个 apk（arm64 和 armeabi），随便选一个，
   装不上再换另一个。
5. 建议把它改个好记的名字，比如：持仓追踪.apk


================================================================
  第 6 步：装到手机上
================================================================
· 方式一（最省事）：用微信/QQ 把 apk 发给自己，手机上点开下载安装。
· 方式二：数据线把手机连电脑，把 apk 拷到手机存储，手机上点开安装。
· 方式三：把 apk 传到手机上的文件管理器里再点开。

安装时会遇到这些提示，都按下面处理：
  · “未知来源应用 / 禁止安装” → 点“设置”→ 打开“允许来自此来源的应用” → 返回继续装
  · “Play 保护机制拦截” → 点“详细信息”→ 选“仍然安装”
  （这是因为 APK 不是从应用商店下的，属于正常现象，不是病毒。）


================================================================
  第 7 步：手机上必做的一次设置（不做可能当天不自动更新）
================================================================
国产手机会杀后台，做完这三步才能保证每个交易日自动出内容：
1. 系统设置 → 应用 / 应用管理 → 找到本 APP → 电池 / 电量管理
   → 选【无限制】或【不优化】。
2. 设置 → 通知 → 允许本 APP 发通知。（后台服务靠常驻通知活着。）
3. 如果手机有“自启动管理 / 关联启动”，把本 APP 加进白名单。

做完之后：
  · 打开 APP，它会自动抓当天数据（约 1 分钟，要联网），
    显示净持仓、隐波基差、涨跌家数、三条判据、结论、次日观察位。
  · 顶部有【立即刷新】和【自动刷新开关】两个按钮。
  · 每个交易日 15:30 收盘后打开，数据最完整。


================================================================
  常见问题
================================================================
Q: 我不注册 GitHub 行不行？
A: 不行，必须要有账号才能用它的免费编译服务器。注册是免费的，只要邮箱。

Q: 编译失败（红色叉）怎么办？
A: 把 Actions 页面里的红色报错信息整个截图，发给帮你做这个程序的人，
   他能根据报错改配置。这不是你操作错了，是编译配置需要调整。

Q: 手机上打开 APP 显示方块字 / 乱码？
A: 说明这台手机缺中文字体，看 android_app\assets\字体说明.txt 里的方法，
   放一个字体文件进去重新编译即可。大部分手机不会遇到。

Q: 周末打开 APP 数据不对？
A: 周末没有交易数据，APP 会自动显示最近一个交易日的。
   另外周末重新抓的期权价格跟交易日收盘时不同（返回的是最新价不是结算价），
   所以周末看到的隐波可能和当天跑出来的有出入 —— 以交易日当天为准。

Q: 主力资金那一栏显示“—”？
A: 那个数据源（东方财富）在部分网络下取不到，属正常，不影响其他结论。

Q: 电脑上的程序还要不要继续跑？
A: 可以两边都跑，互不影响。电脑端继续生成 Excel，手机端看 APP。
   两边用的是同一套分析逻辑，数字一致。

Q: 数据存在手机哪里？卸载会丢吗？
A: 存在 APP 私有目录里，卸载就清空了。不需要任何存储权限，
   也不会往你的相册/下载目录里塞东西。
