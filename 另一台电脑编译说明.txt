================================================================
  在另一台电脑上生成手机安装包（APK）· 说明
================================================================

这个压缩包里是完整的 APP 源码。你把它拷到另一台电脑上，
解压后按下面的路线操作，就能生成 APK 安装文件。


----------------------------------------------------------------
  先看这条：APK 现在还不存在，必须"编译"才会生成
----------------------------------------------------------------
源码不等于安装包。源码是“菜谱”，APK 是“做好的菜”，
中间那一步叫编译，需要专门的工具（安卓 SDK/NDK），
而且要连外网下载约 1.5GB 的工具包，所以：
  · 编译时建议开着梯子（要访问 dl.google.com 和 github.com）
  · 硬盘留 10GB 以上空间，内存 4GB 以上
  · 首次编译 20～40 分钟属于正常


================================================================
  ★ Windows 10 专用：只要双击一个脚本（推荐）
================================================================
前提：Win10 版本 19041 以上（按 Win+R 输入 winver 回车可查看）。

一共就三步：
  1. 双击【Windows一键编译.bat】
     → 它会自动安装 Linux 子系统（WSL + Ubuntu）。
       中途若弹出"是否允许"的窗口，点"是"。
  2. 重启电脑
     → 重启后会自动弹出 Ubuntu 黑窗口，让你设一个用户名和密码
       （密码输入时不显示，输完直接回车）。设完关掉那个窗口。
  3. 再次双击【Windows一键编译.bat】
     → 自动复制代码、下载工具、开始编译，约 20～40 分钟。

编好后 APK 自动放到本目录的 bin 文件夹里，直接拿去装手机。

如果第 3 步报红字失败，看下面"常见问题"里的日志收集方法。
如果 winver 显示版本低于 19041，本方案不可用，请改用路线 C 或 D。


================================================================
  路线 A：另一台电脑是 Linux（Ubuntu 最好）—— 最简单
================================================================
1. 把压缩包拷过去，解压，进入 android_app 目录。
2. 打开终端，依次执行：
       chmod +x build_apk.sh
       ./build_apk.sh arm64          （只想编一个包，推荐）
       或 ./build_apk.sh             （编两个包，兼容很老的手机）
3. 中途会问一次 sudo 密码，输入你电脑的开机密码（屏幕上不显示，输完回车即可）。
4. 出现 “完成！APK 在 bin/ 目录” 就成了，APK 在 android_app/bin/ 里。


================================================================
  路线 B：另一台电脑是 Windows —— 要先装 WSL（Linux 子系统）
================================================================
Windows 本身编译不了安卓 APK，必须借一个 Linux 子系统。
1. 右键开始菜单 → 选“终端(管理员)”或 PowerShell(管理员)，执行：
       wsl --install -d Ubuntu
   装完会要求重启，重启后会自动弹出 Ubuntu 窗口，
   让你设一个用户名和密码（密码输入时不显示，输完回车）。
2. 在 Ubuntu 窗口里，先把压缩包拷进 Linux 的家目录：
   最简单做法：在 Windows 上把压缩包复制到 C:\Users\你的用户名\ 下面，
   然后在 Ubuntu 窗口里执行（把文件名换成实际名字）：
       cp /mnt/c/Users/你的用户名/安卓APP打包.zip ~/
       cd ~ && unzip 安卓APP打包.zip && cd android_app
3. 执行：
       chmod +x build_apk.sh
       ./build_apk.sh arm64
4. 完成后，在 Windows 的文件管理器地址栏输入：
       \\wsl$\Ubuntu\home\你的用户名\android_app\bin
   就能看到 APK 文件了。

（如果你电脑上装了 Docker Desktop，也可以走路线 C。）


================================================================
  路线 C：用 Docker（Windows / Linux / macOS 都能用）
================================================================
前提：装好 Docker Desktop 并启动。
在解压出来的 android_app 目录下执行一条命令即可：

  docker run --rm -v "%cd%":/home/user/hostcwd kivy/buildozer android debug

（Linux/macOS 把 %cd% 换成 $(pwd)）

第一次会拉一个很大的镜像，之后同样要等 20～40 分钟。
生成的 APK 同样落在 android_app/bin/ 目录里。


================================================================
  路线 D：都不行，还是用 GitHub 云端编译
================================================================
看同目录下的【手把手教程.txt】，
或者双击【推送到GitHub.bat】按提示操作。
好处是不用装任何环境，缺点是要在 GitHub 上注册账号。


================================================================
  拿到 APK 之后怎么装到手机
================================================================
1. 用微信/QQ 把 apk 发给自己，或者数据线拷到手机，点开安装。
2. 提示“未知来源”→ 点设置 → 打开允许 → 返回继续装。
   提示“Play 保护机制”→ 点详细信息 → 仍然安装。
   （不是病毒，只是因为不是从应用商店装的。）
3. 装完必做一次设置，否则国产手机会杀后台、当天不自动更新：
     设置 → 应用 → 本 APP → 电池 → 选“无限制 / 不优化”
     允许通知；有“自启动管理”就加白名单。


================================================================
  常见问题
================================================================
Q: 编译报红字失败了怎么办？
A: 把报错的最后 30 行截图，发给帮你做这个程序的人。
   大多数情况是 NDK 版本或依赖问题，改一下配置就能过。
   你在终端里执行下面这条命令可以把日志存成文件，方便发给别人：
       buildozer -v android debug 2>&1 | tee build.log

Q: 手机装不上 APK？
A: 先确认手机是安卓 8.0（Android O）以上。
   如果编了两个包（arm64 和 armeabi），换另一个试试。

Q: 手机打开是方块字/乱码？
A: 少数手机缺中文字体。看 assets\字体说明.txt，
   放一个中文字体进去重新编译即可。大部分手机不会遇到。

Q: 手机上要挂梯子吗？
A: 不用。APP 只访问东方财富、新浪、中金所这些国内网站。

Q: 周末打开 APP 数据不对？
A: 周末没有交易数据，APP 会自动显示最近一个交易日的。
   周末重抓的期权价格跟交易日收盘时不同（是最新价不是结算价），
   所以隐波可能和当天跑出来的有出入 —— 以交易日当天为准。

Q: 电脑上的程序还要继续跑吗？
A: 可以两边都跑，互不影响。电脑端继续生成 Excel，手机端看 APP，
   两边同一套分析逻辑，数字一致。
